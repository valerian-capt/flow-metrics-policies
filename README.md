# Flow Metrics public policies

This repository contains only the public policy website for Flow Metrics for Jira.

- Public privacy policy: https://valerian-capt.github.io/flow-metrics-policies/privacy/
- Publisher: flowmetrics.expert
- Contact: flowmetrics.expert@cadensight.com
- Current policy: cloud production extension 0.93.1, effective 20 October 2026.

GitHub Pages publishes the root of `main`; `.nojekyll` serves the static HTML/CSS.
No JavaScript, external fonts, analytics or build dependencies are used.

Keep `privacy-policy.md` and `privacy/index.html` consistent when changing policy
wording. Review changes against the shipped extension before publishing. This
repository does not contain extension code, test access or reviewer credentials.
